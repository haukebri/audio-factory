A second diagnostic, `HF_HUB_OFFLINE=1 .runtime/judge-venv/bin/python .runtime/judge-preflight/features.py`, compared the installed MLX frontend with `WhisperFeatureExtractor.from_pretrained` from the exact artifact. MLX implements its own HTK-style, unnormalized filterbank; the reference processor uses its trained frontend. Both have 128×201 bins, but maximum absolute filterbank difference is **1.0**, with sums **198.5 versus 3.1909855285406996**. See `feature-diagnosis.json` and runtime `_init_mel_constants` / `_extract_features`. This is an evidenced preprocessing incompatibility and a plausible contributor; the experiment does not prove it is the sole cause of unusable replies. Replacing that harness-only allocation with a plain namespace produced the recorded comparison. No runtime/model bytes were patched.
